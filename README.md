# OCaml Practice

## Description
This repository contains **OCaml** exercises focused on functional programming concepts. The implementations include working with recursive data structures, balance checking for mobiles, and evaluating mathematical expressions using OCaml's pattern matching and recursion.

### Key Features:
- **Mobile structure and balance checking**: Recursively checks if a mobile is balanced based on its branches' length and weight.
- **Expression evaluation**: Implements basic operations such as addition, subtraction, multiplication, division, and sigma notation for summation.
